## Description: 
Pour l'animation visuel, j'ai choisi des petites videos visuelles libre de droit sur pixabay et pexcels. La plupart des sons viennent de son qui existe déjà. Les sons pour lesquels j'ai, si on peu dire, plus de mérite serait ceux que voici:  celui du feu d'artifique où à partir d'un explosion sur jsfxr, j'ai modifié quelques parametres dont celui qui l'alongeant, donnait davantage l'effet d'un feu artifice. Pour le bruit de Le bruit de petard dans la sequence du phoque, j'ai modifier sur jsfxr un bruit d'explosion pour que ca sonne plutot comme un pétard. Mon idée dans cette sequence était d'émettre un bruit alarmant qui ferai crier le phoque. Sinon, dans la troisième séquence, en voulant savoir si j'y arriverait, j'ai tenté d'imiter le bruit de corde de guitard à partir d'un synth (sur jsfxr aussi). J'ai joué avec les parametres dans l'intention de me rapprocher le plus possible du bruit d'une corde de guitard (ce sont les premiers son de guitar qu'on entend).
